# MAJEX · lançamentos

Landings dos produtos digitais da MAJEX. Cada pasta é um projeto na Vercel (Root Directory = a pasta).

| Pasta | Produto | Checkout |
|---|---|---|
| `excel/` | Excel no Piloto Automático | pay.cakto.com.br/32fovny |
| `app/` | Do Zero ao App com IA | pay.cakto.com.br/or8fdfq |
| `conta/` | Conta em 10 Minutos | pay.cakto.com.br/xkn5p4v |

Ver localmente: `node serve.js` e abrir http://localhost:8770/excel/

Pixel: preencher `TIKTOK_PIXEL` (e `META_PIXEL`) no bloco CONFIGURAÇÃO do fim de cada index.html.
Os parâmetros utm_*, ttclid, fbclid e gclid da URL são repassados para o checkout.
